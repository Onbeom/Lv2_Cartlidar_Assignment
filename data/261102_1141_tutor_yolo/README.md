## 후보 C 를 B 대신 쓸지 판정 기준(결과 보기 전에 적음 · 사용자 확인 2026-11-02, 헛검출 ≤ 15 → ≤ 10 으로 사용자 수정)
1. (기존 승인 기준 그대로) 실물 평가 203장: 짝 지은 퍽 중 모양 ≥ 95 %.
2. 실물에서 B 보다 나빠지지 않음: 검출 TP ≥ 362(B 366 − 1 %), **헛검출 ≤ 10**(B 는 Python 평가 11 · C++ 후처리 9 — 같은 Python 평가로 재면 B 자신도 넘지 못하는 값), 색 100 %. 헛검출은 B · C 를 같은 도구(`zeroshot_b.py`, conf 0.25 · NMS 0.45)로 잼.
3. 근접 개선: 튜터 154225 test 재현율 ≥ 0.95 · 모양 ≥ 0.98.
- 셋 다 통과면 C 로 바꾸고(가중치 · ONNX · SHA 새로, PC TensorRT 동등성 다시) 인지에 통보. 하나라도 실패면 B 유지.
- 한계: 튜터 자료도 합성이라 **실물 팔 카메라 근접 성능은 여전히 미검증**.
