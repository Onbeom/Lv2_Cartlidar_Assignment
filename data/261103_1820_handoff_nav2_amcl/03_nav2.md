# 03. Nav2 (설계 45, B안 차체)

## 구성
```
bt_navigator(BT: replan_only_after_failure) → planner_server(Smac Lattice) → smoother_server
→ controller_server(RotationShim + Regulated Pure Pursuit, 20 Hz) · behavior_server  ─ /cmd_vel_ctrl
→ velocity_smoother → /cmd_vel_smoothed → collision_monitor → /cmd_vel_cm
→ turn_floor.py(마지막) → /cmd_vel_nav (TwistStamped, frame base_link) → 팀 twist_mux nav(10)
```
- 제어점 `robot_base_frame: rotation_center`(정적 TF base_link → rotation_center, x = x_icr). 스키드 차체는 회전 중심이 몸 x 축 위 뒤쪽이라, 그 점을 제어점으로 써야 제자리 회전 · 경로 추종이 맞음.
- footprint(rotation_center 기준) x −0.0892 ~ 0.3288, y ±0.171(B안: base_link 기준 −0.155 ~ 0.263). 전역 costmap 만 `footprint_padding` 0.04.
- 전역 costmap 층: `/map`(SLAM 벽) + `/map_objects`(고정 물체) + inflation. 라이다 장애물 층은 전역에서 뺌(벽 점이 스캔마다 달라 다시 계획이 잦았음, 설계 28). 지역 costmap 에는 있음.
- params 의 `map_server` · `map_objects_server` · `map_saver` 절은 쓰지 않아도 됨(지도는 localization 패키지가 띄움).
- 목표 도착 허용 xy 0.025 m · yaw 0.05 rad. 진행 검사 `required_movement_radius` 0.25 m · `movement_time_allowance` 15 s.
- 값마다 이유: `reference/design_docs/nav2_params_v45_changes.md`(v21 → v45 표). 큰 갈림길:
  - NavFn → Smac(Hybrid → **Lattice**): 점 로봇 경로가 출발 통로 ㄱ자 모퉁이 기둥을 깎음. Lattice 동작 표 = 직선 · 제자리 회전 · 반경 0.25 호.
  - MPPI → **RPP + RotationShim**: MPPI 가 후진 끊는 점이 있는 경로를 지름길로 깎음. RPP 자체 충돌 검사는 끔(안전은 collision_monitor, 설계 38).

## 보정 노드 `turn_floor.py`(Nav2 체인 맨 끝, 모의 인자)
| 기능 | 모의 값 | 왜 |
|---|---|---|
| 제자리 회전 바닥값 `w_min` | 0.19(원하는 실제 회전) | 4륜 스키드는 작은 회전 명령에 차체가 안 돌고 바퀴만 미끄러짐(모의: 명령 0.02~0.10 rad/s 에서 참 회전 0 %) |
| 제자리 회전 앞먹임 `turn_ff` | 켬 | 실제 회전이 명령의 53~75 % → 측정 곡선 역함수로 명령을 키움 |
| 전진 중 회전 앞먹임 `move_ff` | `move_ff_cmd` [0.1 … 0.8] → `move_ff_act` [0.0 … 0.5824] | 전진 중에는 명령 0.17 rad/s 까지 거의 안 돎 → RPP 방향 보정이 안 들었음 |
| `out_frame` | base_link | 제어점이 rotation_center 라 명령 frame 이름이 rotation_center 로 나옴. 스키드는 (vx, wz) 가 어느 점이든 같으므로 twist_mux · 구동이 받는 base_link 로 이름만 바꿈 |
| `yaw_loop`(IMU PI) | 끔 | 시도했다가 RPP 와 엇갈려 흔들림(설계 23) |

- 곡선 · 바닥값은 **Isaac 바퀴 마찰 기준 모의 값**. 실물은 바퀴 · 바닥이 달라 다시 재야 함(제자리 회전 · 전진 중 회전 명령별 실제 회전 속도 → `move_ff_*`, `w_min`). 원래 구동 계층(바퀴 속도 되먹임) 일에 가까워 drive · 펌웨어 쪽에서 풀면 이 노드를 줄일 수 있음.

## 판정 기준(모의, 2026-10-31 승인, `reference/sim_tools/evaluate.py`)
- G1 목표마다 SUCCEEDED · G2 끝 참값 오차 ≤ 0.10 m · yaw ≤ 0.15 rad · G3 주행 내내 footprint 여유 > 0(참값, 벽 · 고정 물체)
- G4 위치 추정 오차 RMSE ≤ 0.05 m · 최대 ≤ 0.15 m · G5 `/cmd_vel_nav` frame base_link, |vx| ≤ 0.20, |wz| ≤ 0.8
- 목표 7 개 `reference/sim_tools/goals_seed1_B2.json`(출발 칸 → 칸 입구 → 태그 12 · 13 · 14 앞 → 출발 복귀). 목표 고를 때 '회전 구간 여유 ≥ 위치 추정 최대 오차' 규칙(AMCL 0.03 m).
