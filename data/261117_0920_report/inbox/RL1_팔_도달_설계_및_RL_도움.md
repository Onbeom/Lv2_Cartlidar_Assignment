## 2. 한 일
### 2-1. RL1 팔 목표 위치 도달 (모의)
- 왜: Isaac Lab 에서 팔 정책을 학습 · 판정하는 틀을 먼저 세우려고.
- 어떻게: Isaac Lab ManagerBasedRLEnv (Franka reach 구조), rsl_rl PPO, 팔 4 관절 위치 목표, 정책 30 Hz. TCP = 두 손가락 가운데 (사용자 결정).
- 실험 · 조건: 차체 고정, 평가 목표 1000 개 (학습과 다른 seed). 판정 J1 3 s 오차 ≤ 10 mm 비율 ≥ 95 %, J2 도달 중앙 ≤ 1.5 s, J3 팔-차체 접촉 0, J4 속도 ≤ 4.50 rad/s · 토크 포화 ≤ 5 %, J5 유지 떨림 RMS ≤ 0.05 rad/s, J6 seed 3 개. 기준은 끝까지 고정.
- 결과 (모의, seed 1): v1 ~ v15 모두 전체 불통과.
  - 가장 나은 v8: J1 92.9 %, J2 1.03 s 통과, J3 접촉 37 구간.
  - v8 + 실행 때 유지 게이트 (진단): J1 94.1 %, J5 중앙 0.0001.
  - 마지막 v15: J1 86.2 %, J2 1.17 s, J3 58, J4 처음 통과 (최대 2.94 rad/s, PhysX 포화 0.34 %), J5 최대 1.01.
- 결론: 사용자 지시 (10-27) 로 v15 에서 멈춤. v16 은 설계만 적고 돌리지 않음.
  - J4 는 사용자 결정으로 계산 토크 대신 PhysX 실제 관절 힘으로 잼. 계산 토크는 움직이는 동안 거의 늘 포화로 셈.

- 왜: 직육면체 퍽이 누워 있을 수 있음 (교수님 추가 설명).
- 어떻게: 설계안 (P1 세우기 새 환경, 퍼텐셜 보상, 반복 규칙) 을 쓰고, 실행은 RL 261110 1 이 함. 이 세션은 판정 기준 · 설계 변경을 승인 / 반려.
- 결과 (모의, RL 261110 1 결과 파일): 채택 정책 r2e.
  - 각본 R0b' 과 비교: 다시 쥐고 들기까지 94.5 % (1451/1536) 대 84.7 %, 칸 넣기까지 78.0 % 대 72.5 %.
- 결론과 이유 (검토에서 정한 것):
  - 칸에 못 앉음의 원인은 손 안 퍽 위치 가정이었음 (가정 없이 1.2 %). #128 과 같은 문제라 새 Issue 대신 #190 댓글로 남김.
  - 옆 퍽 판정을 base 좌표에서 월드 좌표로 바꿈. 차체가 팔 반작용으로 0.2 ~ 0.4° 돌아 생긴 거짓 밀림 때문. 결과를 본 뒤 바꾼 기준이라 옛 판정 불통과도 기록함.
  - E1 '잡는 점 5 mm' 항목을 판정에서 관찰로 옮김. r2d 최대값 4.83 mm 를 보고 정한 문턱이었기 때문.
