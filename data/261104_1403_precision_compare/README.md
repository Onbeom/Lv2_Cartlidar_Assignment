- 한 장 처리는 load_test 의 letterbox + 추론 + 후처리 시간이다.
- 판정:
  - FP16 은 정확도 통과다. 실물 GPU 평균이 53 → 23 % 로 줄었다.
  - INT8 은 두 판 모두 FP32 와 같은 장이 73 % 뿐이다. 판정 재현율도 떨어진다(커튼 앞 −0.065, 경기장 팔 −0.067). 그래서 불통과다.
  - INT8 은 GPU · 속도도 FP16 보다 낫지 않다(25.4 · 24.2 % 대 23.1 %).
- **결론: FP16 을 쓴다(배포는 480 · 384 FP16, GPU 18.9 %). INT8 은 쓰지 않는다.**
- INT8 이 떨어진 이유는 추정이다: 보정 128장(MinMax), 검출 head 의 Conv 까지 INT8. 보정을 늘리거나 head 를 float 로 두면 나아질 수 있지만, FP16 보다 빨라지지 않으므로 하지 않는다.
- 'different models of devices' 경고: 모든 엔진에서 나왔다. 같은 FP32 엔진(sha dbbf4a0b…)의 판정이 11-04 오전 J32 와 한 자리까지 같아서, 결과에는 영향이 없다고 본다.
- 예상과 비교: P16 25 % 예상 → 23.1 %, I8 30 % → 25.4 %, N16 20 % → 18.9 %, I8 정확도 92~97 % → 73 %(예상보다 훨씬 나쁨).
