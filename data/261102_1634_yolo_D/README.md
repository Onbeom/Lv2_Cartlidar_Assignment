## 영상 판정 기준(사용자 11-02 16:3x 결정, 거리 범위는 사용자가 나에게 맡김)
- 대상: 새로 찍는 영상(학습에 안 쓴 장면 · 배치)에서 초당 1장을 뽑아(카메라당 약 270장, 사용자 라벨 부담 고려 — 18:2x 2장 → 1장) 라벨을 단다. 초안은 B · C · D 중 좋은 것으로 만들고, 사용자가 고친다.
- 카메라마다 B · C · D를 같은 장에 돌려 비교한다. **문턱 0.6에서 재현율 ≥ 0.95 그리고 정밀도 ≥ 0.95**인 모델 중 min(재현율, 정밀도)이 큰 것을 그 카메라에 쓴다. 통과한 모델이 없으면 다음 후보를 만든다.
- 앞 · 뒤 D435:
  - 깊이(aligned depth 상자 안 중앙값) 3.0 m 안의 퍽만 센다.
  - 1.0 m 안: 클래스(색 + 모양)까지 맞아야 맞힘이다.
  - 1.0~3.0 m: '작게 찍힌 퍽'이다. 색이 맞는 퍽 검출(0.6 이상)이면 맞힘으로 센다. 모양은 가까이 가서 확인한다(사용자 규칙).
  - 3.0 m 밖의 정답과 검출은 세지 않는다.
- Arducam:
  - 팔 카메라에서 퍽까지 **0.50 m 안**의 퍽만 센다. 근거: mission의 먼 거리 정렬(coarse_distance 0.45 m, 범퍼 기준)이 끝난 뒤 팔 카메라를 쓰고, 여유 0.05 m를 더했다.
  - 깊이가 없으므로 영상마다 크기로 경계를 잡는다. 영상 처음에 목표 퍽을 줄자로 0.50 m에 두고 찍는다. 그때 목표 퍽 상자의 긴 변보다 작은 정답 · 검출은 세지 않는다.
- 한 영상에서 뽑은 장들은 서로 비슷하므로, 결과에 영상별 수치도 같이 적는다.
- (16:4x) 사용자 결정으로 Nav2 세션이 GPU를 먼저 쓴다. 그래서 epoch 6에서 학습을 멈췄다(last.pt 저장됨).
  - 이어 하기는 `resume_d.sh`(resume=True)다. 평가 단계는 train_d.sh와 같다.
