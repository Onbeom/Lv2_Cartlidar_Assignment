# D 엔진 입력을 카메라 화면 비율로 (2026-11-04 10:05)

왜 하는가:
- FP16 시험(`261104_0941_fp16_check/README.md`)에서 찾은 문제를 고치기 위해서다.
  - 정사각 640×640 엔진은 D435 640×480 장에 위아래 80 px 회색 띠를 붙인다.
  - 그 결과 D435 재현율이 PC pt 평가(직사각 입력)보다 낮다. 커튼 앞 0.683 → 0.625, 커튼 뒤 0.662 → 0.595.
- 팀 C++ 검출기(`trt_detector.cpp`)는 엔진 입력 크기를 읽어서 letterbox 한다. 그래서 엔진만 바꾸면 인지 코드는 그대로다.

만든 것(PC):
- `export_480.py` → `yolo11n_task4_D_480.onnx`
  - 입력 [1,3,480,640], 출력 [1,8,6300], sha256 6f2c8738…
  - D435 640×480은 크기 그대로 들어가고 띠가 없다.
- `export_384.py` → `yolo11n_task4_D_384.onnx`
  - 입력 [1,3,384,640], 출력 [1,8,5040], sha256 96ea2647…
  - Arducam 1280×720을 0.5배로 줄이면 640×360이고, 띠는 12 px다. Ultralytics 직사각 입력과 같다.
- 가중치는 D 그대로다(pt sha 35f7af1a…). 학습은 새로 하지 않았다.

PC 도구 확인(ONNX Runtime CPU, `pc_ort_480.py` · `pc_ort_384.py`, judge.py D 고정 설정, @0.6 재현율 · 정밀도):

| 세트 | PC pt(all_D) | 정사각 640 Jetson FP32 | 480 ONNX | 384 ONNX |
|---|---|---|---|---|
| 커튼 앞 | 0.683 · 0.925 | 0.625 · 0.923 | **0.683 · 0.925** | |
| 커튼 뒤 | 0.662 · 0.980 | 0.595 · 0.977 | **0.662 · 0.977** | |
| 오전 앞 | 0.914 · 0.953 | 0.899 · 0.943 | **0.914 · 0.953** | |
| 오전 뒤 | 0.896 · 0.980 | 0.893 · 0.978 | **0.896 · 0.980** | |
| Arducam | 0.959 · 0.951 | 0.950 · 0.950 | 0.950 · 0.943(불통과) | **0.959 · 0.951** |

- 정리: D435는 480 엔진, Arducam은 384 엔진을 쓰면 PC 평가와 같아진다.
- Arducam에 480 엔진을 쓰면 띠가 60 px가 되어 정밀도가 0.95 아래로 내려간다.

Jetson 시험(`pkg/check_480.py`):
- 두 ONNX마다 FP32(--noTF32) · FP16 엔진을 만든다.
- 이미지는 FP16 시험 때 복사한 `~/fp16_check/images` 1478장을 다시 쓴다.
- 결과는 `results/` → PC `analyze_480.py` → `result_480.json`.

기준(Claude가 정함):

| 기준 | 통과 조건 | 예상(실행 전) |
|---|---|---|
| R1 Jetson = PC 평가 | N32(480 · 384 FP32) 판정이 카메라마다 all_D와 ±0.01 안 | 통과(PC ORT가 이미 같음) |
| R2 FP16 | N16 대 N32 같은 장 ≥ 98 %, 판정 차 ≤ 0.01, Arducam N16 ≥ 0.95 · 0.95 | 통과(정사각 640 FP16 시험과 같은 경향) |
| R3 속도 | FP16 infer 중앙값 480 · 384 모두 정사각 640 FP16(6.43 ms) 이하 | 480은 약 0.8배, 384는 약 0.65배(화소 수 비례보다 덜 줄어듦) |

모두 통과하면 인지 세션에 배포 후보로 알린다: D435 480 FP16, Arducam 384 FP16.
- 팀 설정은 엔진 경로가 `detector.engine_path` 하나다. 그래서 팔 카메라에 다른 엔진을 쓸 수 있는지는 인지 세션이 확인한다.
- 안 되면 팔에는 정사각 640 FP16을 쓴다(0.950 · 0.950으로 통과).
