# 추가 실물 자료를 한 번에 모으는 목록

사람이 배치·촬영하는 단계다. 촬영을 시작하기 전까지 현재 코드/모의 작업은 별도로 계속한다. 아래 수집량은 시작안이며 정확도 보장에 필요한 고정 장수라는 뜻은 아니다. 기존391장 원본을 지우거나 다시 찍을 필요는 없다.

## 1. YOLO 색·모양 보완 (필수 · PC에 연결한 실제 사용할 카메라)

서로 다른 배경/배치의 **독립 장면6개**에 빨강 원기둥·초록 원기둥·빨강 직육면체·초록 직육면체를 모두 넣는다. 빨강을 학습/검증/평가3묶음에 독립 배정할 수 있게 하는 것이 우선 목적이다.

- 거리: 0.4m·0.7m·1.0m 부근을 포함한다. 카메라 기준 실제 거리와 카메라 이름을 기록한다.
- 조명: 실제 경기장에 가까운 밝음/어두움·옆광을 포함한다. 자동노출/WB 여부와 설정값을 기록한다.
- 자세: 원기둥은 세움, 직육면체는 세움과 눕힘을 포함한다.
- 구성: 떨어진 물체와 부분 겹침, 영상 가장자리에서 일부 잘림을 포함한다. 알아볼 수 없는 정도의 가림은 무리하게 색/모양 정답을 붙이지 않는다.
- 각 장면에서 독립된 보기 약10장을 선택하면 총60장의 추가 양성 예시가 된다. 영상으로 찍어도 되며 인접프레임을 학습/검증/평가로 나누지 않는다. 최종 사용 장수는 중복/흐림 검사 후 결정한다.
- 현재 신호등/빈배경 영상이 있으므로 동일한 빈 장면만 추가로 많이 찍는 것은 우선순위가 낮다.

## 2. 추적·재식별 평가 (필수 · PC 기록, 실제 사용할 RGB/깊이/CameraInfo/TF가 가능하면 함께)

각 테스트를 짧은 연속 영상으로 남긴다. 정지 사진 묶음은 객체가 바뀌는 순서를 알 수 없어 이 평가를 대신하지 못한다. 퍽 실제 태그 번호가 시작과 끝에서 보이게 한다. 움직인 순서와 실제 ID를 별도 기록한다.

1. 같은 색·모양 퍽2개가 교차하되 태그가 보이는 경우.
2. 같은2개가 잠시 가려졌다가 다시 나타나는 경우.
3. 화면 밖으로 나갔다가 같은 물체가 복귀하는 경우와 다른 물체가 그 자리에 들어오는 경우.
4. 같은 종류 여러 개가 붙어 보이다 다시 분리되는 경우.
5. 태그가 가려지고 상자 일부가 잘렸다가 복구되는 경우.
6. 같은 물체를 앞/뒤 카메라가 번갈아 보는 경우(실제 카메라2대가 준비됐을 때).

모터를 구동할 필요는 없다. 사람이 물체/카메라를 움직여 기록할 수 있다. 단, 카메라를 움직인 영상의3D 추적 평가에는 해당 시각 TF 또는 별도 기준이 필요하므로 RGB만으로 3D 정확도를 주장하지 않는다. 손으로 가린 장면도 가림 자체를 기록하며 숨겨진 물체 위치를 정답으로 추정해 넣지 않는다.

## 3. 센서·배포 준비 (필수 · Jetson, 장비 단계)

Jetson에서 실제 OS/JetPack/CUDA/TensorRT/Isaac ROS 버전과 카메라 모델명을 확인한다. PC용 엔진을 그대로 복사해 실행하지 않는다. 제가 전달하는 ONNX·클래스표·고정 입력 예시로 대상 엔진을 만들고 출력 비교를 한다. 이 단계의 명령은 실제 Jetson 환경을 확인한 뒤 맞춰 제공한다.

## 4. nvblox (설치·장비 준비 후)

PC nvblox 설치는 사용자가 나중에 하기로 했다. 실행할 때는 깊이·CameraInfo·단위·해상도·촬영 시각 TF를 먼저 확인한다. 사람/장애물 시험 전에 고정 물체의 지도 위치·사라진 장애물 잔상·입력 중단 유효 상태부터 본다. 실제 사람을 향해 주행시키거나 장애물을 로봇에 던지는 방식으로 초기 시험을 시작하지 않는다.

제가 생성하는 자료: 같은 클래스 정의의 Isaac Sim 배치/거리/조명/카메라 변화와 상자 라벨, 정답ID/자세를 가진 가림·교차·재등장 시퀀스. 모의 결과와 실제 촬영 결과는 별도 표로 기록한다.

## 5. 실제 SLAM 입력 확인 (필수 · Jetson/PC, 사용자 장비 단계)
실제사용할차체고정D435의좌우IR·CameraInfo·앞뒤라이다·clock/TF와가능하면wheel odom을같은bag에기록한다. 정지→짧은직진→좌우회전→출발점복귀의실제거리/각도기준을따로남긴다. 모터구동은제어담당/사용자단계이며제가실행하지않는다. 기존모의직접결합은두조명모두정확도기준미달이므로모의통과라고대신하지않는다. 보정·동기·가림·추적유효성과odom반영설정을분리해확인할자료다.
