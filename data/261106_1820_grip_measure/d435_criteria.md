# D435 로 쥔 퍽 보기: 판정 기준 (실행 전 작성, 2026-11-07, 모의)
사용자 조건: 벽 · 상자에 닿으면 안 되고, 퍽을 땅에 떨어뜨리면 안 된다.

| 항목 | 값의 의미 · 단위 | 기준 | 예상 |
|---|---|---|---|
| 퍽 떨어뜨림 | 보는 자세를 오가는 중 떨어뜨린 대(`transit_drop`) · 운반 미끄럼(`carry_slip`), 원본 평가 대비 증가, 대 | 0 | 0 안팎. 퍽이 수직에서 약 75° 기울지만 쥐는 힘으로 버틸 듯, 모름 |
| 상자 접촉 | 넘겨받기 구간 팔-상자 최대 힘, N | 원본 평가보다 늘지 않음 | 안 늘어남. 몸 쪽으로 접으므로 |
| 벽 · 상자 여유 | 이동 중 팔 · 집게 · 퍽이 집기 자세보다 앞으로 더 나가는 거리, m (기하 계산) | 0 이하 | 0 이하 |
| 몸체 접촉 | 팔-몸체 최대 힘, N | 원본 평가보다 늘지 않음 | 팔을 뒤로 눕히므로 D435 기둥 · 팔레트에 닿을 수 있음, 모름 |
| 손 안 변화 | 넘겨받기 → 보는 자세 → 앞 운반 자세 사이 퍽 이동 p95, mm | ≤ 0.5 | #128 '쥔 뒤 미끄러짐 0.5 mm 이하' 와 비슷 |
| 손 안 기울기 변화 | 같은 구간 p95, ° | ≤ 1 | 작음, 모름 |
| 정착 | 보는 자세 도착 뒤 집게 끝이 0.5 mm 안에 멈추는 시간 p95, s | ≤ 1.0 | 처짐 보정 적분 때문에 1 s 안팎 |
| 이어서 성공 | 집기 → 보기 → 칸 넣기 성공 대, 원본 평가 대비 | 떨어지지 않음(48대 흔들림 ±4 를 192대로 ±8 로 봄) | 비슷 |
| 깊이 오차 | 렌더, 손가락 표시 기준, 잡음 · 오차 포함, 수평 깊이 p95, mm | ≤ 1 | 통과 쪽. 1 mm 약 2.9 px, 태그 · 윤곽이 다 보임 |
| 기울기 오차 | 같은 조건 p95, ° | ≤ 2 | 통과 쪽 |
