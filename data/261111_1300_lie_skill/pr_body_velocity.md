## 무엇
누운 직육면체 세워 놓기 스킬 `lie_upright`(#193, PR #203)에서 미션 순서 모의로 찾은 것을 노드에 반영합니다.
- **관절 속도 제한 방식:** `lie_upright.velocity_limit` = scale(기본)을 새로 넣었습니다. 관절 목표 변화가 상한을 넘으면 관절마다 자르지 않고, 행동 전체(잡는 점 변위 · β · ρ 변화)를 같은 비율로 줄입니다(`lieApplyActionLimited`). 상한은 2.0 → 3.0 rad/s입니다.
- **상자 보기 자세:** `[∓0.30, −1.80, 0.50, 1.90, 0]` → `[∓0.30, −1.25, 0.15, 1.85, 0]`. 옛 자세는 관절 2가 많이 접혀 팔이 차체에 닿았습니다.
- **놓음 판정 수평 기준:** 잡는 점 대신 퍽 중심 추정(잡는 점 + 집게 방향 × 11 mm)과 세울 자리 D를 비교합니다(`release_center_offset`). 학습의 '세울 자리 3 cm 안'은 퍽 중심 기준이기 때문입니다.

## 왜
- 노드는 실물 안전을 위해 관절 속도를 제한해야 합니다. 그런데 관절마다 자르면 모의 성공률이 크게 떨어졌습니다. 기준은 제한 없음 96.4 %입니다.

  | 상한 | 관절마다 자름 | 비율로 줄임 |
  |---|---|---|
  | 3.0 rad/s | 79.4 % | 95.4 % (통과) |
  | 2.0 rad/s | 4.5 % | 90.6 % |

- 옛 보기 자세는 모의에서 팔-몸체 7.9 N, 관절 2가 −1.76에서 막혔습니다. 새 자세는 0 N입니다.

## 시험 (PC · 모의)
- 빌드 경고 0, control · robot_policy 시험 모두 통과(새 gtest: 비율로 줄일 때 방향 · β 유지, 제한이 없으면 그대로). Isaac r2e 평가는 접촉 없는 성공 기준, 512대 × 3 seed입니다.
- 새 보기 자세로 집는 상자 place_box 모의 렌더 120장을 판정했습니다. 120/120 통과, 중심 최대 0.71 mm · 요 0.14°입니다.
- 미션 순서 모의 1536대: 칸에 넣기까지 80.5 %. 정책 단계 하락의 주원인은 퍽 긴 축 관측 고정이고, 정책 이어 학습으로 따로 다룹니다.

## 한계
- 실물에서 관절이 3 rad/s를 내는지는 재지 않았습니다(#201에 측정 요청). 못 내면 상한과 정책을 다시 봅니다.
- 노드 안에서 정책을 돌리는 흐름은 PC에서 실행하지 못했습니다(ONNX Runtime C++ 없음). 모의 · 계산 비교만 했습니다.
