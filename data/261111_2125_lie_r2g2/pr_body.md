## 무엇
- 누운 직육면체 세우기 정책을 r2e 에서 r2g2 로 바꿨습니다(`robot_policy/config/models/lieupright_r2g2.onnx`, `policies.yaml` lie_upright `model`).
- r2g2 가 무엇을 학습에 넣었는지 `policies.yaml` 머리 주석에 적었습니다. 노드 동작 · 설정 값은 바꾸지 않았습니다.
- 코드 주석의 학습 설정 이름을 r2g2 로 고치고, r2e 기록에서 나온 수치에는 r2e 라고 표시했습니다(`manipulator_node.cpp`, `lieupright.hpp`).

## 왜
- r2e 는 노드와 다른 관측으로 학습해서, 노드 방식(퍽 · 긴 축 · 옆 퍽은 시작 때 잰 값 고정)으로 돌리면 모의 성공률이 90.2 % 로 떨어졌습니다.
- r2g2 는 노드 관측 · 관절 속도 비례 축소 3.0 rad/s · 놓음 규칙을 넣고 다시 학습한 것이고, 미션 순서 정책 단계 모의 98.9 % 입니다(#192).

## 시험
- Isaac r2g2 정답 벡터 3 에피소드(315 스텝)와 C++ `control/lieupright` 를 스텝마다 비교했습니다. 관측 45 최대 1.2e-6, 쥠 칸 0 스텝 다름, 세울 자리 7.5e-9 m. 관절 목표는 최대 6.7e-4 rad 이고, 315 스텝 중 2 스텝에서 비례 축소 배율이 이분법 한 단계(1/256) 갈린 곳입니다.
- 배포 ONNX 에 기록 관측을 넣으면 기록 행동과 최대 8.6e-6 차이입니다. 빌드 경고 0, control · robot_policy 시험 79 개 통과.

## 한계
- 모의 기록과의 비교이고 실물에서는 돌리지 않았습니다. 관절 속도 상한을 3.0 rad/s 넘게 올리려면 다시 평가해야 합니다(4.0 은 모의 90.3 % 로 불통과).
