# 자기 깊이 필터 ROS 연결 조건

(필수 · PC 시제품, Jetson 별도 확인) 오프라인 캐시와 개인 ROS 노드 시제품을 구현했다. 팀/실물 운용 통합은 아직 아니다.

- 입력: 원시 깊이·같은 해상도/광학 프레임의 CameraInfo·영상 시각의 base_link→광학 프레임 TF·관절 상태·모델 SHA256. 실물 원시/정렬 깊이는 각 CameraInfo와 일치시킨다.
- 출력: 같은 header/frame_id/encoding/해상도를 유지한 깊이. 로봇 영역만 0으로 무효화한다. 장애물 의미분류 결과를 기다리거나 가려진 뒤쪽을 자유공간으로 채우지 않는다.
- 캐시 키: 모델 SHA256, 광학 frame_id, 해상도, K, 로봇 기준 카메라 변환, 자기형상에 영향을 주는 관절 자세. 월드에서 차체 위치만 달라지고 자기 상대 기하가 같으면 재사용 가능하다.
- 캐시 키가 바뀌면 이전 캐시를 적용하지 않는다. 새 캐시가 준비되지 않은 프레임은 nvblox 통합 입력에서 보류한다. 원본 깊이를 우회 전달해 자기 장애물을 다시 누적하지 않는다.
- 영상 시각의 TF·관절 상태가 없거나 시각 관계를 확인할 수 없으면 보류한다. 최신 TF를 과거 영상에 대신 쓰지 않는다. 동기화 허용 범위는 실제 수신 시각과 로봇 움직임 자료를 확보한 뒤 정한다.
- 캐시는 현재 자세에서만 검증했다. 관절 값을 임의 반올림해 캐시 적중률을 높이지 않는다. 허용 자세 변화량은 별도 검증 전 0으로 둔다.
- 고정 자세의 반복 적용 p95가 33.3ms 이하여도, 생성 지연·영상 변환·TF 대기·ROS 전달·nvblox 계산을 포함한 전체 30Hz 성공을 뜻하지 않는다.
- 현재 모의 검증은 noise 없는 같은 장면의 drive/stow/zero다. 깊이 노이즈·관절 지연·외부 물체가 팔에 닿은 경우·다른 배치·실물 및 Jetson은 검증하지 않았다.

개인 ROS 시험에서 두 자세·두 인코딩의 출력 보존, 캐시 변경 중 보류, 50ms 초과 관절 입력 보류, 미지원 왜곡 입력 거부를 확인했다. 50ms는 이번 PC 연결시험의 게이트이며 실물 동기화 허용 오차로 확정하지 않는다. 실물/다른 장면 검증 후 팀 반영은 사용자 허가를 받는다.
