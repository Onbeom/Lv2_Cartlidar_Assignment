# 261103_1114 장소 상자 윗면 찾기 (팔 Arducam, 모의)

목적: 놓기 위치를 발제 지도 좌표 대신 **눈앞 장소 상자 기준**으로 정한다. 상자는 돌아가 있거나 밀려 있을 수 있다(사용자 11-03).
가정은 세 가지다(사용자 결정 11-03).
- L1·L2·L3 모두 205×205×70 mm 상자 1개다.
- 상자는 바닥에 놓여 있다.
- 태그 위치에는 기대지 않는다. 주행은 TFmini로 상자 면 앞 0.02 m까지 다가간다.

## 방법 (`detect_box.py`, 시제품)
1. 팔을 내려다보는 자세로 둔다(`view_pose.py`, B URDF 정기구학). joint 0, −0.65, 0.00, 1.95, 0이면 카메라가 상자 윗면 약 0.20 m 위에서 0.5° 기울기로 내려다본다. 이때 상자와 둘레 30 mm가 화면에 들어온다. 화각은 가정값이다(가로 113°, 1280×720).
2. 윗면 높이(0.07 m) 평면을 정사영 영상(1 mm/화소)으로 펼친다(호모그래피). 그러면 윗면은 실제 크기 정사각형으로 보인다.
3. 크기를 아는 정사각형을 거친 격자에서 고운 격자로 찾는다(중심, 요 ±45°). 점수는 세 가지로 매긴다.
   - 변마다 안팎 Lab 대비의 중앙값을 더한다.
   - 네 변 안쪽 색이 서로 다르면 깎는다.
   - 가장 약한 변의 대비를 더한다.
   - 퍽 색 화소(빨강·초록, perception.yaml HSV 범위)는 표본에서 뺀다.
4. 변마다 경계점을 화소 이하로 찾고, 정사각형에 Huber 가중 최소제곱으로 맞춘다.
5. 방향은 90°마다 같으므로 로봇 기준 0°에 가까운 것을 고른다(상자가 45° 넘게 돌지 않는다고 가정).

## 자료 (`render_place_box.py`, Isaac Sim 6.1)
- 로봇은 B안 light USD·URDF이고 최종 자리에 있다.
- 상자 요는 ±30°, 옆은 ±5 cm다. 앞뒤는 TFmini 빔(y 0)이 닿는 면이 차체 앞 + 0.02 m가 되게 두었다.
- 상자 위에는 이미 놓인 퍽 0·2·5·9개를 둔다(참 칸, 원기둥·직육면체, 빨강·초록). 조명은 두 단계다.
- 색은 발제 월드와 같게 했다(바닥 0.45 회색, 상자 0.8·0.68·0.48). 실물 색은 모른다.
- 설계용(`design/`, 시드 1, 40장면×2)은 방법을 맞추는 데만 썼다. 판정용(`judge/`, 시드 2, 60장면×2)은 방법을 고정한 뒤 한 번만 쓴다.

## 판정 기준 (제안, 사용자에게 알림 11-03)
장마다 세 가지를 모두 지키면 통과다. 기준은 판정용 120장 모두 통과다.
- 상자 중심 오차 ≤ 5 mm
- 방향 오차 ≤ 1°
- 칸 9개 중 최대 오차 ≤ 6 mm

발제 판정 허용은 10 mm다(mission_plan.yaml verify.tolerance 주석).

## 한계
- 모의 렌더에는 렌즈 왜곡, 잡음, 실물 색·조명, 팔 처짐, 관절 오차가 없다.
  - 카메라 자세는 정기구학 그대로다.
  - 실물 정확도는 Arducam 보정(camera_info, 왜곡 큼)과 팔 관절 정확도에 달려 있다. 관절 1틱(0.088°) × 팔 0.3 m는 약 0.5 mm다.
- 화각과 해상도는 가정값이다(sensors.yaml). 실물 화각이 더 좁으면 상자가 화면에 다 들어오는지 다시 봐야 한다.
- 중심에 0.35 mm 고정 치우침이 남는다(정사영 화소 반올림으로 보임).

## C++ 이식 · 노드 연결 (브랜치 `fix/perception-place-box`, dev c27d100 위)
- 모듈은 `perception/include/perception/place_box.hpp`(헤더만, ROS 무관)이고 Python 시제품과 같은 계산이다. 거친 격자만 각도별로 여러 스레드에 나눴고 답은 같다.
- 노드:
  - 서비스 `/perception/place_box/measure`(std_srvs/Trigger)로 시작한다. READ_TAG나 ARM_ALIGN이 켜져 있어야 한다.
  - 팔 영상 3장에서 찾은 값을 odom으로 모아 중앙값을 낸다.
  - 출력은 `/perception/place_box`(PoseStamped), `/perception/place_box/cells`(PoseArray, 칸 9개 행 우선), `/perception/place_box/status`(String JSON)이고, 셋 다 latched다.
  - 장마다 흩어짐이 3 mm 또는 1°를 넘으면 결과를 내지 않는다.
- 확인 도구:
  - `src/place_box_check_main.cpp`: 영상 한 장 → x y yaw. `check_cpp.py`가 정답·Python 결과와 견준다.
  - 노드 재생: `run_node_check.sh` + `node_check.py`, ROS 도메인 93, 영상 QoS reliable 설정 사본.
