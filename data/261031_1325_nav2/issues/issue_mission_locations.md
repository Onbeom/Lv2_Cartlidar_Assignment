## 요청 (인지 파트 → mission)

저장 지도(map_mission)로 Nav2(AMCL · MPPI)를 2D 운동학 모의에서 확인했습니다(Isaac · 실물 시험 아님). 이 지도의 `map` 좌표는 **발제 도면 좌표**입니다(출발 상자 중심 = (0.734, 0.95)).
`mission/config/mission_table.yaml` 의 `locations` 는 `home: [0.0, 0.0, 0.0]  # = slam_toolbox map_start_pose` 로 출발 자세를 원점으로 두고 있어 이 지도와 맞지 않습니다. 아래 확인 부탁드립니다.

1. `locations` 를 발제 좌표로 바꿔 주세요. 모의에서 도착까지 확인한 자세(배치 seed_1 기준, `[x, y, yaw]`, m · rad):

| 이름(예) | 자세 | 메모 |
|---|---|---|
| home (출발 복귀) | [0.724, 0.95, 3.1416] | 출발 상자 중심에서 x −0.01 m(제자리 회전 여유 0.021 → 0.031 m) |
| start_box_1 | [2.2325, 0.6663, 2.7862] | |
| L1_via | [4.080, 0.410, 1.5708] | L1 칸 입구. **L1 앞에 꼭 거쳐야 함**(없으면 상자 모서리에서 못 꺾어 들어감) |
| L1 (tag 12, +x 면) | [4.158, 0.895, 2.9997] | 앞 카메라–태그 0.45 m |
| L2 (tag 13, −y 면) | [2.202, 2.6945, 1.5708] | 앞 카메라–태그 0.45 m |
| start_box_3 | [2.5752, 4.6227, 1.1125] | |
| L3 (tag 14, +x 면) | [4.163, 5.354, 3.1416] | 앞 카메라–태그 0.45 m |

2. 출발 자세(출발 상자 중심, yaw π)의 제자리 회전 여유는 **0.021 m** 입니다. `read_tag` 의 회전 탐색(30° × 11 = 한 바퀴)을 출발 자세에서 하면 벽과 2 cm 거리로 돕니다. 회전 탐색 위치를 옮기거나 회전 범위를 줄일 수 있는지 봐 주세요.
3. 태그 앞 목표(L1 · L2 · L3)에서 **범퍼–상자 면 거리는 0.12~0.13 m** 입니다(카메라 거리 0.45 m 기준). 이 자리에서 팔 자세(READY · PLACE 등)를 바꾸면 상자에 닿을 수 있습니다(control `align.coarse_min 0.30` 과 같은 이유). 그 자리에서 할 팔 동작과 필요한 거리를 알려 주시면 목표를 다시 계산하겠습니다.
4. L1 · L3 칸은 제자리 회전 여유가 좁습니다(목표 자세에서 들어올 때 · 나갈 때 회전 구간 여유 0.072 · 0.077 m). 태그 앞에서 다른 회전 탐색을 하지 않는 순서가 안전합니다.

근거: 2D 운동학 모의(라이다 2개 · 바퀴 오도메트리 잡음), 위 목표 7개를 3회(잡음 seed 3개) 모두 도착 · 충돌 없음 · 위치 추정 RMSE ≤ 0.026 m 로 통과. 배치 seed 가 바뀌면 자세도 다시 계산해야 합니다.
