## 설계 (mission, 기본 꺼짐 `start_box.enabled: false`)
1. 잴 자리: 시작 박스 `goto` 뒤 `approach` 앞(대기 자리, standoff 0.30 ~ 0.45). FINE 자리에서는 상자 가까운 변이 앞 D435 화면 아래 끝(바닥 x 0.255 vs 변 0.260)이라 못 잰다.
   - `goto x y yaw` 를 approach_poses.yaml 의 stage 와 맞춰(mission 이 이미 읽음) 접근 키(B<n>:<side>) · final · turn_range_deg 를 얻는다. kind box 이고 뒤에 집기 줄(target_look)이 있을 때만 `measure_start` 단계를 끼운다.
   - 사전값 = final xy + 0.3625 m × 앞 방향(FINE 자리 상자 중심, 모든 접근 같음: 앞 끝 0.1328 + gap 0.1272 + 반 변 0.1025). measure_front → 상자 odom (x, y, yaw) 저장. 지도 자리에서 max_shift(0.08) 넘게 멀거나 실패하면 그 박스는 계획 그대로(지금과 같음) + 기록.
2. target_look 다시 계산: 계획 줄 `target_look:base_footprint:lx:ly:z` 와 앞의 turn 이름 각 t 로 회전 전 자리 P0 = C + R(t)(lx − C, ly) 를 되살려(C = CENTER_X −0.04035) 상자 틀의 퍽 자리 local = P0 − (0.3625, 0) 를 얻는다(S · N 접근은 (0, ±0.04), W · E 는 (±0.04, 0)). 잰 상자로 odom 의 퍽 자리 = 상자 중심 + R(yaw_box) local → `target_look:odom:x:y:z` 로 바꿔 보냄(회전과 무관, toppick_tilt 실패 뒤 재시도 때도 같은 값).
### 계산으로 찾은 것 (설계 전에, 계산)
- 제자리 회전은 J1(팔 밑동) 자리만 옮긴다. 정책의 닫힘 방향은 J1 → 퍽 방향이므로, 맞출 것은 'J1 → 퍽 방향 = 퍽 면 방향'이다.
- ±30° 로 돌리면 J1 은 옆으로 최대 d·sin30 = 0.068 m 움직인다. 퍽까지 약 0.27 m 이므로 방향은 약 ±14° 만 바뀐다. 그래서 회전만으로 맞출 수 있는 β 에 한계가 있다.
- **#226 의 '기본각 + β' 는 방향이 반대다**: 왼쪽 퍽(lat +0.04)에 β = +10° 면 '기본각 + β'(27°)의 면 어긋남은 14.7° 로, 그대로 둘 때(10.1°)보다 나쁘다. 맞는 회전은 −2.7° 다(아래 식).
- 왼쪽 퍽, 밀림 0, 범위 ±30°:

| β | 기본각 그대로 | 기본각 + β | ±30 안 최적(θ) | β 가 반대쪽(−β) 일 때 최적 |
|---|---|---|---|---|
| 5° | 5.0 | 7.4 | 0.0 (+7.1) | 0.0 |
| 10° | 10.1 | 14.7 | 0.0 (−2.7) | 4.4 |
| 15° | 15.3 | 21.1 | 0.0 (−13.1) | 9.3 |
| 20° | 20.5 | 26.4 | 0.0 (−25.8) | 14.1 |
| 30° | 31.2 | 37.2 | 8.8 (−30) | 23.7 |
| 45° | 42.3 | 36.2 | 24.4 (−30) | 27.9 |
- 최적으로 돌려도 β ±45 · 밀림 ±5 cm 에서 남는 면 어긋남은 최대 34° 다(β −40°, 왼쪽 퍽). 20° 를 넘는 경우는 |β| 가 약 20 ~ 25° 를 넘고 불리한 쪽일 때다. 이 경우는 회전만으로 못 맞춘다. 맞추려면 면에 수직으로 다시 서야 한다(#229 비스듬히 서기와 같은 방식, 큰 변경 → 다음 일로 제안).

3. 회전각: turn 단계 시작 때 TF 로 퍽 자리 P(base_footprint) 와 β = 상자 요 − 차체 요(±45° 로 접음, 직육면체 면 90° 주기)를 구한다.
   - J1 → 퍽 방향이 면 방향 β' 가 되는 회전(계획기 기하, C 둘레): θ(β') = β' − asin((sinβ' (Px − C) − cosβ' Py) / d), d = J1_X − C = 0.13635. β' = 0 이면 계획기 turn_deg(asin(lat/d)) 와 같다.
   - 직육면체 면은 90° 마다 같으므로 β' ∈ {β, β ± 90°} 를 모두 보고, 허용 범위 [max(lo, −30), min(hi, 30)] 안에서 남는 면 어긋남이 가장 작은 θ 를 고른다(풀이가 없거나 범위 밖이면 범위 끝 중 어긋남이 작은 쪽, 같으면 |θ| 작은 쪽). |θ| < 0.5° 면 turn_0. 이름 turn_<p|m><θ 소수 1 자리>.
   - 남는 면 어긋남 r 은 정책이 받는다. r > `residual_warn_deg`(20) 이면 경고 기록만(멈추지 않음).
   - 원기둥은 계획에 turn 줄이 없다 → 회전 안 함, target_look 만 다시 계산.
4. ③ 정책 집기: manipulator `skill.enabled` 는 launch 인자(`skill_enabled:=true`)라 mission 이 바꿀 수 없다. start_box.enabled 를 켤 때 같이 켜야 한다고 설정 주석 · PR 에 적는다.
5. 계산은 `mission/start_box.hpp`(헤더 함수) + gtest. mission_node 는 `measuredPick(step)` 을 measuredPlace 옆에 둔다.
