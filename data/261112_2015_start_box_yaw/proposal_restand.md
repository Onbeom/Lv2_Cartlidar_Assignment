# 제안: 시작 박스 '면에 수직 다시 서기' (#226 다음 일, 11-13)

## 왜
- 제자리 회전(±30°)만으로는 J1 → 퍽 방향이 약 ±14° 만 바뀐다. 상자 |β| 약 27° 넘는 불리한 쪽은 남는 면 어긋남이 20° 를 넘는다(β ±45 최대 34°, 계산).
- k9(#245, 모의) 20 ~ 30° 77.9 · 30 ~ 45° 63.2 %(horizon 1.0 가정 86.5 · 74.3 %)로 0 ~ 20°(82 ~ 98 %)보다 떨어진다.

## 무엇 (mission, #247 위, 설정 `start_box.restand` 기본 false)
1. measure_start 뒤 그 접근의 직육면체 집기마다 남는 각 r 을 미리 셈(#247 의 sb_choose_turn).
2. r > restand_deg(20) 인 집기가 있으면 접근을 바꿈: 잰 상자의 '가장 가까운 면' 바깥 법선 위에 같은 standoff 로 새 stage, 같은 gap 으로 새 final 을 잡음(상자 틀이 β 만큼 돈 접근 자세표 항목).
   - 퍽 lat 은 상자 틀 기준 그대로(±0.04)라, 새 자리에서 계획기와 같은 turn(±17°)이 그대로 맞는다(β' = 0).
3. 새 stage 로 /drive/navigate → approach(FINE) → 원래 줄(turn · target_look · toppick) — target_look 은 #247 대로 odom 자리.
4. 새 자세가 지도에서 막히면(외곽 + 0.05 가 벽 · 기둥 · 다른 박스와 겹침) 원래 접근 + 회전(#247)으로 하고 기록.
