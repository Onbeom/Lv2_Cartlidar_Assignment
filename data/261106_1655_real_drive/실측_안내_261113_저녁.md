```bash

```

배치: 노트북을 로봇 앞 약 37 cm, 화면을 뒤로 젖혀 팔 카메라 쪽(경첩 약 115~130°), 뒤에 받쳐 고정, **화면 밝기 20 %**.
2-1. (필수 · PC) 보드를 노트북 전체 화면으로
```bash
eog -f /home/pa4/git/lv2_next_module/261106_1655_real_drive/jetson/charuco_6x4_5x5_100.png
```
2-2. (필수 · Jetson) 짧게 확인(ALIGN + 주변 3 자세, 약 2 분). 엔터 뒤 20 초 안에 노트북을 보드 화면으로
```bash
sleep 20; cd ~/real_drive && python3 arm_handeye.py --auto --board 6x4 --sweep 3 --out ~/real_drive/handeye/p2b_1113e
```
끝나면 `q` → 채팅에 "확인 끝". 코너 ≥ 10 이 안 나오면 2-3 으로 넘어가지 않음.

## 3. BOXLOOK 첫 재실행 (PLACE 한 자세, 약 3 분)
배치: 노트북을 7 cm 상자 위에 180° 펴서 눕힘, 6x4 보드 전체 화면, 밝기 20 %, 위 테두리를 로봇 쪽으로. **모터 전원 스위치에 손.**
3-1. (필수 · 사람) 화면 유리 윗면의 바닥 위 높이(mm), 수평계 화면 위 · 로봇 옆 바닥(°)
3-2. (필수 · Jetson) 잰 값 적기(밑줄을 바꿔서)
```bash
mkdir -p ~/real_drive/handeye/boxlook_1113 && echo "화면 유리 윗면 높이 ___ mm, 화면 수평 ___°, 바닥 수평 ___°, 칸 49.17 x 48.75 mm" > ~/real_drive/handeye/boxlook_1113/measure.txt
```
3-3. (필수 · Jetson)
```bash
sleep 20; cd ~/real_drive && python3 arm_handeye.py --auto --no_sweep --board 6x4 --extra ~/front_cal/fk_poses.yaml --extra_names BOXLOOK_PLACE --out ~/real_drive/handeye/boxlook_1113
```
