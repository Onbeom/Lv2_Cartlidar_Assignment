화면이 하나뿐인 것을 전제로, **로봇 조작은 모두 자동**입니다. 사람이 하는 것은 배치 · 물건 놓기 · 엔터 · 값 적기뿐입니다.
명령마다 어느 컴퓨터에서 치는지 적었습니다. "Jetson" 명령은 PC 터미널에서 아래 0-2 로 들어간 셸에서 칩니다.
끝나면 결과를 PC 로 가져오고(맨 아래), 해석은 Claude 에게 "실측_안내_261112 결과 해석해줘" 로 맡깁니다.

## 0. 준비 (켤 때마다)

0-2. (필수 · PC) Jetson 에 들어가기 (비밀번호 안 물음, 프롬프트가 cart11@… 로 바뀜)
```bash
ssh -o ControlPath=~/.ssh/lv2_jetson.sock cart11@cart11.local
```
0-3. (필수 · Jetson) 12 V 와 두 보드 확인 — 두 줄 모두 '정상'(약 12 V, 오류 CMD_TIMEOUT 만)이어야 함
```bash
cd ~/real_drive && python3 check_boards.py
```
- 전압 0 V · SYNCREAD · FAULT 면: 12 V 공급 확인 → 12 V 켠 채 보드 리셋 → 다시 확인 (11-12 에 겪음)
0-4. (필수) 팔 근처에 벽 · 상자 · 사람 없음, 바퀴를 막아 차체 고정. 멈춤: 터미널에서 `space`(그 자리 HOLD), 급하면 12 V 끔(팔이 처지니 받칠 것).

## 1. P2b 손-눈 보정 + 카메라 높이 (자동, 약 10 분) — 다른 세션 요청과 한 번에

배치(필수): 노트북을 로봇 앞 35~45 cm 의 **7 cm 상자 위**(또는 바닥)에 눕히고 화면 위 테두리를 로봇 쪽으로. 촬영 중 움직이지 않게 고정.
적을 것(필수): 화면 가운데 높이(바닥부터, 상자 포함) · 수평계 값. 칸 크기는 이 노트북 전체 화면에서 27.8 mm(가로 10 칸 277.5 · 세로 7 칸 194.5 mm).

1-1. (필수 · Jetson) 20 초 뒤 시작 — 엔터 뒤 20 초 안에 노트북에 보드를 전체 화면으로 띄움
```bash
sleep 20; cd ~/real_drive && python3 arm_handeye.py --auto --extra ~/front_cal/fk_poses.yaml --out ~/real_drive/handeye/p2b_1112
```
1-2. (필수 · PC, 새 터미널 창) 보드 띄우기
```bash
eog -f /home/pa4/git/lv2_next_module/261106_1655_real_drive/jetson/charuco_10x7_5x5_100.png
```
자동 진행: STOW → DRIVE → ALIGN → ALIGN 주변 26 자세(보드 코너 ≥ 20 이면 저장) → **BOXLOOK_PLACE**(보드 코너 54 개가 다 보이게 노트북만 옮김, 최대 2 분 기다림, 3 장) → **BOXLOOK_TAG**(같음) → DRIVE → STOW.
- BOXLOOK 에서 노트북을 옮겼으면 그 자리의 화면 높이 · 수평계를 다시 적기
- 끝나면 터미널에 '자동 끝: 저장 N 장' → `q`
1-3. (필수 · Jetson) 적은 값 남기기 (예시 숫자를 바꿔서)
```bash
echo "손눈: 화면높이 ___ mm, 수평 ___° / PLACE: 높이 ___ mm, 수평 ___° / TAG: 높이 ___ mm, 수평 ___° / 칸 27.8 mm" > ~/real_drive/handeye/p2b_1112/measure.txt
```
