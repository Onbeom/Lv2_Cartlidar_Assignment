제목: perception_survey: 색·모양은 팔 카메라 태그 관측을 D435 검출보다 먼저 쓰기

## 무엇
- 등록부가 색·모양 표를 팔 카메라 태그 관측(camera=arm, ID 있음)과 그 밖(D435)으로 나눠 모으고, 팔 표가 있으면 그 표로만 정한다. 팔 표가 없을 때만 D435 표를 쓴다. 팔 표끼리 엇갈리면 지금처럼 완료를 거부한다. ID·자세·최소 관측 2 규칙은 그대로.
- 시험 2개(팔 우선, 팔 표가 없을 때 D435 충돌 거부)와 README 한 줄.

## 왜
- YOLO 후보 C 엔진으로 B0 판정 재생(24회)을 다시 돌리자 23/24였다. D435 한 장이 서 있는 빨강 원기둥을 직육면체(점수 0.787)로 봐서 표가 갈렸고, 그 회가 완료 거부됐다(틀린 완료는 0).
- 기록된 모든 모의 재생에서 팔 태그 표는 8640개 중 틀림 0, D435 표는 3846개 중 틀림 1(이 경우)이었다. 가까이서 본 팔 관측을 우선하는 편이 근거가 강하다.

## 시험 (모의, PC)
- colcon test perception · perception_survey 175/175. 새 시험 1개는 옛 코드에서 실패함을 확인.
- B0 판정 렌더 24회 재생(YOLO 후보 C, PC TensorRT FP32): 24/24 · 288/288, 틀린 완료 0, ID·색·모양·자세 틀림 0, 중심 최대 6.07 mm, 무응답 0. 바꾸기 전 23/24.
