# 실물 바코드 라벨 찾기 설계 (팔 Arducam 1280 × 720) · 2026-11-05 (설계, 판정 아님)

왜: 실물 첫 판정(`261104_1754_tag_barcode_real`)에서 바코드 4개를 1038장 모두 못 읽었다(B1 실패). 표본으로 원인을 봤다.
- 라벨은 선명하지만 흰 여백이 좁고 둘레가 무늬 있는 카펫이다. 그래서 Code 128 의 조용한 구역이 없고, zbar 가 기호를 하나도 못 찾는다. 모든 바코드 종류를 켜도 같다.
- 팀 설정 감마 2(모의용)는 실물의 회색 막대를 번지게 해 반대로 작용한다.

설계(브랜치 `fix/perception-barcode-label`, 작업 트리 `~/git/Lv2_Cartlidar_Assignment_bclabel`, dev 30c2d1f 위, 커밋 전):
- `BarcodeReader` 에 라벨 찾기 길을 더했다(`BarcodeLabelConfig`, `set_label`). 전체 장 길 앞에 먼저 한다.
  1. 문턱 = rel 0.85 × 밝기 99.5 백분위(5×5 흐림 뒤)
  2. 바깥 윤곽 → 넓이 0.004~0.5 · 가로세로비 1.8~6 · 채움 ≥ 0.75 · 큰 것 3개
  3. 볼록 껍질을 4점으로 줄여 원근 보정한다. 4점이 아니면 최소 외접 사각형으로 돌린다.
  4. 흰 여백 0.35 를 붙이고 감마 0.5 를 적용한 뒤, 각 0 · ±4 · ±8 로 zbar 를 돌린다.
  - 여기서 기호(quality ≥ 4)가 하나라도 나오면 그것으로 결정한다. 문자열이 둘 이상이면 거부한다.
  - 하나도 안 나오면 예전 전체 장 길(감마 2 · ±30°)로 넘어간다.
- `perception_node.cpp`: `barcode.read_label.*` 파라미터. `perception.yaml`: `read_label` 절(enabled true).
- `barcode_compare --read <목록> [배율 감마 q] label.enabled=1 label.<이름>=값`: 출력에 label · labels 를 더했다.
- 단위 시험: BarcodeReader 7/7(새 2개: 좁은 여백 · 카펫 무늬 위 원근 라벨 읽기, 다른 문자열 둘 거부 · 라벨 없음 · 꺼짐).
  - 전체 단위 시험 수는 아직 colcon test 로 다시 세지 않았다.
- 시제품: `proto_label.py`(Python, ctypes zbar). 집계: `score.py`.
