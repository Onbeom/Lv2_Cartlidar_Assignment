# 실물 팔 카메라로 바코드 · AprilTag 읽기 (로봇 없이, Jetson) · 2026-11-04

무엇: 로봇 없이 팔 카메라(Arducam)만 들고 찍어, 인지 코드로 바코드 4개 · 퍽 태그 12개 · 장소 태그 3개를 읽는다. Jetson 에서 걸리는 시간도 잰다.
- 찍는 것은 모두 같은 거리이고, 거리는 사용자가 알려 준다(사용자 11-04: 손으로 거리 · 기울기를 여러 가지로 맞추기 어려움).
- 읽기 코드는 인지 패키지 그대로 쓴다(8fcf9f8 = PR #103, Jetson `~/e2_engine_check` 빌드).
  - 바코드: `barcode_compare --read`(BarcodeReader, 인지 설정 read_scale 1 · gamma 2 · quality 4 · 회전 후보 0 ~ ±30°)
  - 태그: `tag_read`(이 폴더, perception::TagDetector tag36h11 · 인지 노드와 같은 생성 인자, ID 만)
- 해상도는 1280 × 720 MJPG 로 OpenCV V4L2 에서 직접 연다. 처음에는 팀 설정(bringup `sensors.launch.py` usb_cam 640 × 480)과 같게 했으나, 640 × 480 은 화면에 줄이 생겨(사용자 11-04 확인) 바꿨다. YOLO 팔 평가도 1280 × 720 이다. usb_cam 드라이버 자체는 보지 않는다.
- 보정(camera_info)은 쓰지 않는다. 노드도 바코드는 원본 장으로 읽고, 태그 ID 는 보정 없이도 나온다. 보정은 태그 자세 · 거리(퍽 위치)에 필요하고 이 시험 범위 밖이다.

도구 (`jetson/`, Jetson `~/tag_barcode_check/` 로 복사):
- `capture.sh` · `capture.py`: Jetson 모니터(DISPLAY=:0)에 화면을 띄우고, ssh 터미널에서 `<이름> <거리cm>` Enter 로 녹화 시작, 빈 Enter 로 끝, `q` 로 종료. 장마다 PNG(화면 글자 · 십자선 없는 원본) + `meta.json`.
- `read_all.sh`: `tag_read` 빌드 → 모든 장을 바코드 · 태그 두 가지로 다 읽음 → `summarize.py` 표.
- PC 도구 확인(판정 아님, 11-04 17:5x): 렌더 바코드 4장 + 합성 태그(ID 3 · 12) 6장으로 읽기 · 집계가 맞게 나옴(4/4 · 3/3 · 3/3, 잘못 읽기 0).

이름: 퍽 태그 `tag00` ~ `tag11`, 장소 태그 `L1` · `L2` · `L3`(ID 12 · 13 · 14), 바코드 `P2-01` ~ `P2-04`. 한 번에 하나만 화면에 넣는다.
