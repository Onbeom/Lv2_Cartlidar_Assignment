# WaffleExport 2

Fusion에서 원래 `assembly` 탭을 열고 Shift+S → WaffleExport의 실행 삼각형을 누르세요.

- `1`: 기존 G 저장공간 투입·회수 경로 재생 (402프레임, 목표 12fps).
- `2`: 관절과 동작 파일의 재생 준비 상태 확인.
- 재생 창의 취소 버튼: 중단하고 실행 전 관절 자세로 복원.

30×30×60mm 물체는 임시 Custom Graphics로만 표시됩니다. 삭제한 시연용 컴포넌트를 복구하거나 새 설계 부품을 추가하지 않습니다. 재생 종료 시 임시 그래픽을 제거하고 시작 관절값과 카메라를 복원합니다. 기존 부품의 표시·불투명도는 변경하지 않습니다. 관절을 움직이므로 Fusion의 문서 수정 표시가 생길 수 있습니다.

이 기능은 기존에 검사한 경로의 시연입니다. 이후 치수나 배치를 바꾸면 충돌 및 실제 로봇 제어 경로는 다시 검증해야 합니다. ROS/실제 모터로 명령을 보내지 않습니다.

기존 `assembly_request.json`이나 STEP 내보내기 설정이 남아 있어도 자동 유지보수·재내보내기를 실행하지 않습니다. 예전 코드는 `WaffleExport_legacy.py`에 보관했습니다. 명시적인 `maintenance: true` 요청에서만 이전 진입점을 사용합니다.

최근 결과는 `player_status.json`, 오류 상세는 `player_error.txt`에 기록됩니다.
