## 관절 목표 (scale 3.0)
- `arm_target`: 최종 값입니다. 노드 `lieApplyActionLimited`와 같은 비례 축소를 하고, 직전 목표 ± 3.0/30 rad로 한 번 더 자릅니다.
- `vl_scale`: 고른 배율입니다(1 = 안 줄임). ep0에서 107스텝 중 40스텝을 줄였고, 최소 배율은 0입니다.
- `ik` · `dq_ik`: 줄이기 전(배율 1)에 한 번 푼 값입니다. 배율 1인 스텝에서는 `arm_target` = clamp(clamp(before + dq_ik, q ± 0.25), lo, hi)와 같습니다.
