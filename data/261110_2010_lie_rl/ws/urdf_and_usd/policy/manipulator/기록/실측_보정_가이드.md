# 매니퓰레이터 실측 · 보정 가이드 (2026-11-10)

강화학습 세션에서 분리한 실물 측정 안내. **실측은 이 문서를 가진 세션 (실물 담당) 이 하고, 결과 파일을 강화학습 세션에 넘긴다.**
강화학습 세션은 받은 값을 시뮬레이션 기준값 · 무작위 범위 · 꺼내기 / 넣기 경로에 반영해 이어 학습한다 (아래 "결과 넘기기").

- 목표: 11-13 (금) 까지 단계별 성공률 98 % 이상. 시뮬레이션 PPO 결과만으로는 실물과 다르므로 **측정 -> 반영 -> 재학습 -> 재측정** 을 반복.
- 경기 기준 (발제 v5 + 팀 확정): 놓기 성공 = 칸 중심 10 mm 이내 + 2 초 안정, 퍽 바닥 Z 70. **L1 · L2 · L3 모두 205 × 205 × 70 상자** (실제 경기장, 발제 PDF 의 L2 820 받침대 아님). 차체는 상자 앞면 5 ~ 6 cm 에 멈춤. 시간 제한 없음.
- 관련 이슈: developlcy-oss/Lv2_Cartlidar_Assignment#190 (강화학습 진도 · 현황).

## 좌표 · 용어

- **원점 = 관절 1 축 중심 (J1 모터 축)**: 앞 +x, 왼 +y, 위 +z. 로봇 설계 좌표 (base_link) 로는 x 에 96 mm 를 더함, 높이는 base_link 원점이 바닥 위 6.75 mm.
- **잡는 점** = 양쪽 손가락 패드 사이 한가운데 (gripper_roll_link + 140 mm). 퍽을 쥘 때 잡는 점 = 퍽 중심 + 15 mm (위).
- 시뮬레이션 팔 관절 = joint1 ~ joint5 (joint5 = 손목 롤). **실물 6 번째 관절 `gripper_roll` = 집게 개폐 모터** (열림 −0.764, 닫힘 0.923 rad, `control/config/manipulator.yaml`).

## 실물 ROS 2 인터페이스 (팀 저장소 `workspace/docs/interfaces.md`)

| 이름 | 종류 | 용도 |
|---|---|---|
| `/arm_controller/follow_joint_trajectory` | Action `control_msgs/FollowJointTrajectory` | 관절 6 개 (joint1 ~ 5, gripper_roll) 자세 |
| `/joint_states` | `sensor_msgs/JointState` (100 Hz) | 관절각 읽기 |
| `/manipulator/execute_skill` | Action `robot_interfaces/ExecuteSkill` (`policy`, `timeout`) | 팀 스킬: `pallet_load_<열>_<칸>_tilt` (칸에 넣기), `pallet_unload_<열>_<칸>_tilt` (칸에서 꺼내기), 열 1 ~ 3 · 칸 0 ~ 3 |

**안전**: bringup 은 띄우고 미션은 시작하지 않은 상태. 조이스틱 비상정지를 손에 쥠. 동작 시간 6 초 (느리게). `manipulator_node` 가 스킬을 실행하는 중에는 아래 `arm` 명령을 보내지 않음.
**첫 확인**: 0 자세 -> A 자세로 갈 때 팔이 **앞으로 내려가는지** 눈으로 확인 (관절 2 · 3 부호가 시뮬레이션과 같다는 전제). 반대면 즉시 멈추고 강화학습 세션에 알림.

## 측정 항목

### 1. 관절 영점 · 처짐

**영점 (5 분)**: `arm 0 0 0 0 0 && joints`. 설계 0 자세 = 윗팔 (관절 2 ~ 3) 수직, 아랫팔 (관절 3 ~ 4) 수평, 집게 수평 · 정면. 휴대폰 수평계를 링크 윗면에 대고 0° (윗팔 90°) 에서 벗어난 각 = 그 관절 영점 오차. 관절 1 은 집게가 차체 정면 중앙선에서 좌우로 벗어난 mm.

**처짐 (자세 4 개 × 3 번, 빈손 · 퍽 쥠 각각, 30 분)**: 자세마다 잡는 점의 바닥 위 높이와 관절 1 축에서 수평 거리를 줄자로.

| 자세 | 관절 1 ~ 5 (도) | 명령 | 설계 높이 (바닥 위) | 설계 수평 거리 |
|---|---|---|---|---|
| 0 | 0, 0, 0, 0, 0 | `arm 0 0 0 0 0 && joints` | 325 mm | 316 mm |
| A 놓기 시작 (60°) | 0, −14, 17, 57, 0 | `arm 0 -0.2454 0.2999 0.9927 0 && joints` | 175 | 200 |
| B 집기 시작 (45°) | 0, −19, 32, 32, 0 | `arm 0 -0.338 0.559 0.564 0 && joints` | 180 | 220 |
| C 칸 3-1 위 6 cm (60°) | 172, −10, −22, 92, 0 | 아래 순서 | 248 | 191 (뒤쪽) |

C 로 가기 (앞 높은 자세 -> 관절 1 회전 -> 칸 위):

```bash
arm 0 -0.6875 -0.1959 1.9306 0 && arm 2.9998 -0.6875 -0.1959 1.9306 0 8 && arm 2.9998 -0.1708 -0.3884 1.6063 0 && joints
```

C 에서 돌아오기:

```bash
arm 2.9998 -0.6875 -0.1959 1.9306 0 && arm 0 -0.6875 -0.1959 1.9306 0 8
```

퍽 쥔 상태: 손가락 사이에 퍽을 대고 6 번째 값 0.923 (닫힘) 으로 같은 자세 (예 `arm 0 -0.2454 0.2999 0.9927 0 0.923`).
읽은 관절각을 `meas_fk.py` 에 넣은 설계 위치 − 줄자 실측 = 처짐, 명령각 − 읽은 각 = 추종 오차.

### 4. 칸별 넣기 시험 (칸마다 10 회, 시간 없으면 쓰는 칸부터 5 회)

1) 퍽을 손가락 사이에 대고 닫기 (팀 운반 시작 자세 q_front):

```bash
arm 0 -0.2923 -0.1141 1.9772 0 0.923
```

2) 넣기 (예 3-1):

```bash
ros2 action send_goal /manipulator/execute_skill robot_interfaces/action/ExecuteSkill "{policy: pallet_load_3_1_tilt, timeout: 40.0}"
```

3) 결과 기록 -> 4) 다시 꺼내기:

```bash
ros2 action send_goal /manipulator/execute_skill robot_interfaces/action/ExecuteSkill "{policy: pallet_unload_3_1_tilt, timeout: 40.0}"
```

스킬이 시작 자세 등으로 거부하면 메시지를 그대로 기록.
결과: 성공 / 끼임 (벽 위에 걸림) / 기울어짐 / 튕겨 나감 / 옆 칸 퍽 건드림. 어긋난 방향 = 로봇 기준 앞 · 뒤 · 왼 · 오른 (퍽이 칸 중심에서 어느 쪽으로 걸렸나). 실패가 한쪽으로 몰리면 칸 좌표 오프셋 -> 바로 보정 가능.

### 5. 퍽 무게 · 마찰

- 무게: 0.1 g 저울, 원기둥 3 · 직육면체 3.
- 마찰: 같은 재질 판 위에 퍽을 **눕혀** 올리고 (세우면 미끄러지기 전에 넘어짐) 천천히 기울여 미끄러지기 시작하는 각 θ (휴대폰 각도계) 5 회. 조합 3 가지: 퍽–상자 윗면, 퍽–손가락 패드, 퍽–팔레트 칸 바닥. 마찰계수 = tan θ:

```bash
python3 -c "import math,statistics as s; a=[22.5,23.1,21.8,22.9,22.4]; m=s.mean(a); print(f'평균 {m:.1f}° -> 마찰계수 {math.tan(math.radians(m)):.2f}')"
```
