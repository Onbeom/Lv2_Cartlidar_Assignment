#192 누운 직육면체를 세운 뒤 다시 집어 칸에 넣는 미션 흐름을 Isaac에서 끝까지 이어 돌려 봤습니다(모의). 세워 놓기 정책 r2g2(PR #215 · #217) 뒤 단계에서 두 가지가 보여 공유합니다. 고칠 곳은 다시 집기(toppick_tilt)와 칸 넣기 쪽이라 확인을 부탁드립니다.

## 조건 (모의)
- 순서는 노드와 같습니다: ALIGN_A → target_look → 상자 보기 → READY_POSE_45 → r2g2(관절 속도 scale 3.0) → 위로 빼기 → D target_look → toppick_tilt 고정 동작(5 cm 위 · 3 cm 안쪽 → 직선 하강 → 쥠 → 5 cm 들기, 벌림 50 mm, 반경 −2 mm) → 칸 궤적(pallet_place_traj.json, 처짐 보정 ki 4, pallet.speed 0.8).
- 512대 × seed 777 · 778 · 779, 옆 퍽 없음. 다시 집기 · 칸 넣기 평가 코드는 dev `chain_pallet_eval.py`의 고정 동작 집기와 같고, 세워 놓은 끝 상태에서 이어 받게만 고쳤습니다.
- 세운 퍽 자리 측정 오차는 σ 2 mm로 가정했습니다(target_look이 잰 자리 = 참 + 잡음).

## 결과
| 구간 | 결과 (3 seed 합) |
|---|---|
| 세워 놓기(r2g2) | 1529/1536 (99.5 %) |
| 다시 집기 | 1489/1529 (97.4 %) |
| 칸에 앉음 | 1309/1536 (85.2 %) |

## 1. 다시 집기 중 팔-상자 접촉 (사용자 기준 실격)
- 다시 집는 1529대 중 84대(5.5 %)가 상자에 1 N 넘게 닿았습니다. 칸 궤적 구간에서는 0입니다.
- 측정 오차를 0으로 둬도 비슷했습니다(seed 777: σ 2 mm 32대 · σ 0 35대). 그래서 오차가 아니라 고정 동작 경로 쪽으로 봅니다.
- 세운 퍽의 J1 거리(0.27~0.33 m)나 면 각도로는 갈리지 않았습니다.
- 부탁: toppick_tilt 접근 · 하강 경로가 상자 윗면이나 모서리에 닿는지 확인해 주세요. 접근 높이, 안쪽 거리, 하강 자세를 보시면 될 것 같습니다.

## 2. 칸 넣기가 다시 집기 측정 오차에 민감함
- seed 777, 같은 끝 상태 510대 비교:

| 측정 오차 | 다시 집기 | 칸 넣기 | 이어서 성공 |
|---|---|---|---|
| σ 2 mm | 96.9 % | 89.7 % | 86.9 % |
| σ 0 | 98.2 % | 96.8 % | 95.1 % |

- 오차가 없으면 노드 방식 넣기 결과(#205, 약 97 %)와 같습니다. 측정 오차 2 mm가 손 안 어긋남(넘겨받을 때 집게 방향 · 옆 약 2 mm)으로 이어지면서 칸에 못 앉는 대가 늘어납니다.
- 부탁: 칸 넣기가 손 안 어긋남 ±2 mm 안팎에서도 앉도록 할 방법이 있는지 봐 주세요. 예를 들면 놓기 직전 높이 · 머묾, 처짐 보정, 반경 목표입니다. 인지 쪽(target_look 정밀도)은 우리가 따로 봅니다.
