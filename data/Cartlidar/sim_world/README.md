# 가상 과제 월드 (인지 파트 시험용) — 최종 과제(B조 주사위) 판

Isaac Sim 6.1용 USD 월드다. 2026-10-23 확정된 과제(신호등 12회 점멸 → 선반 3개에 주사위 3개)에 맞췄다.
**모르는 값은 가정이거나 도메인 다양화로 무작위**다. 팀 저장소에는 넣지 않는다(학습 폴더 `Cartlidar/`).
과제 공개 전 판(파란 퍽, 6면 18 mm 태그, Aruco 마커, 판정 W1~W6 결과)은 `v1_pre_task/`와 `results/check_261023_1112/`에 그대로 둔다.

## 구성 (가정값은 `build_task_world.py` 의 `A`)

## 실행 (PC)

질감(태그 0~14, 바코드 4장) 다시 만들기 — 결과는 `textures/`:
```bash
~/isaacsim-venv/bin/python -I make_markers.py
```
월드 만들기 — 결과 `worlds/b_dice/seed_<n>/task_world.usda`, `layout.json`:
```bash
~/isaacsim-venv/bin/python -I build_task_world.py --seed 1
```
작업 확인용 위에서 본 그림(판정 아님):
```bash
~/isaacsim-venv/bin/python -I preview_top.py worlds/b_dice/seed_1/layout.json results/preview_261023/top_seed1.png
```

## 물리 수치 v12로 맞춤 (2026-10-24, 모의)

시뮬레이션 세션의 v12 기준 채택(2026-10-24)에 맞춰 로봇 물리 수치를 바꿨다. 근거·값: `261022_2119/변경요약_시뮬레이션_261023.md` 3절.

| 항목 | 이전(v8) | 지금(v12) |
|---|---|---|
| 바퀴–바닥 마찰 정지/운동 | 0.8 / 0.6 | **0.3 / 0.225**, 합치는 방식 average(PhysxMaterialAPI) |
| 팔 위치 drive kd | 24 N·m·s/rad | **36** (kp 400 그대로) |
| armature(kg·m²) | 없음 | **바퀴 0.0163 · 팔 0.045 · 집게 0** (`physxJoint:armature`) |
| 팔·집게 강체 CCD | 없음 | **speculative 켬** (`physxRigidBody:enableSpeculativeCCD`, 강체 7개) |

- 이 파이썬(`-I`)에는 PhysxSchema가 없어 PhysX 속성 이름으로 직접 썼다. 물리 시험은 armature를 실행 중 API로 넣었으므로, 재생을 시작해 PhysX에서 다시 읽는 확인을 따로 했다(`check_physics_v12.py`). 결과 `results/physics_v12_261024/seed_{1,2,3}.json`: seed 3개 모두 armature 13개 관절이 기대값과 같고, 팔 kd 36.0(SI), 마찰 0.3/0.225 average, CCD 7/7이다.
- 배치는 바뀌지 않았다(layout.json에서 `assumptions`를 빼면 이전과 같음). USD 차이는 위 물리 속성뿐이다.
- 다시 판정: `results/check_261024_1946/` — **W1~W7 모두 성공**(seed 1 · 2 · 3).
- 이전 월드는 `worlds/b_dice_v8_261023/`에 그대로 둔다(렌더 도구 확인 34차 `render_check_261023_*`는 v8 월드로 찍었다. 렌더에는 물리 수치가 쓰이지 않는다).
