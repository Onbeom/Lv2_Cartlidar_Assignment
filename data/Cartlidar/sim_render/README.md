## ROS 재생 도구 확인 (2026-10-24, 모의, 판정 시험 아님)

Isaac Sim이 저장한 영상을 ROS 토픽으로 재생해 인지 노드(팀 저장소 `feat/perception-pucks` 60dd1b5)에 넣는다. Isaac Sim–Lyrical 브리지를 검증하기 전이라 이 방법을 쓴다.
가설(실행 전): `가설_재생도구확인_261024.md`.

- `urdf_chain.py`: URDF 고정 관절 사슬로 base_footprint → 카메라 변환을 구한다(numpy만 씀).
- `render_signal.py`: 로봇 자세(신호등에서 칸 가운데 쪽으로 `--dist` m, 정면에서 `--bearing`°) × URDF 장착 자세로 **실제 앞 D435 위치에서** 상태 4개(off·red·yellow·green)를 렌더한다. 로봇 몸체는 렌더하지 않는다.
- `replay_ros.py`: `/clock`, `/tf`(odom → base_footprint), 앞 D435 컬러·깊이(32FC1)·CameraInfo를 발행하고 `/perception/set_mode`로 READ_SIGNAL을 켠 뒤 `/perception/signal`을 기록한다.
  - `stream`: 점멸 시간표대로 30 fps(R2 방식).
  - `lockstep`: 한 장씩 내고 그 장의 결과가 올 때까지 시계를 민다(R1 방식, 프레임별 상태).
- `run_replay.sh`: robot_state_publisher(URDF) + 인지 launch(설정 사본에서 `image_qos: reliable`만 바꿈) + 재생. 도메인 87, 같은 PC 안.

실행 (PC, 모두 저장소 밖 학습 폴더 `lv2_next_module`에서). `<setup.bash>`는 팀 저장소를 빌드한 install의 setup.bash다.
```bash

```
```bash
Cartlidar/sim_render/run_replay.sh 261022_2119/urdf/waffle_4wd_description_261022_2119/urdf/waffle_4wd.urdf Cartlidar/sim_render/results/replay_261024_tool_stream <setup.bash> -- --render Cartlidar/sim_render/results/render_signal_261024_tool --pose p00_d0.60_b+0_e1 stream --sequence RYYYGGGYRRYG --t-on 0.536672 --t-off 0.982663 --t-term 4.92132 --cycles 4
```
