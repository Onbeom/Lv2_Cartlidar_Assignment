# B0 퍽 등록부 모의 검증

기반: B0_발제반영.md ④ 고정12칸 계약. 런타임은 월드의 정답 배치를 읽지 않고 발제의 박스 중심6개와 관측만 사용. 개인 코드 단계, 팀 반영 전 사용자 허락 필요.

| 항목 | 예상(실행 전) | 결과 |
|---|---|---|
| S1 6월드×12칸 등록 | 72/72 일치·위치오차≤10mm. 박스당80mm 간격은35mm 결합 문턱보다 크며, ±30° yaw로 초기 칸 오차는약21mm | **통과:72/72, 최대2.868mm** |
| S2 불완전·충돌 입력 완료 거부 | 전부 거부. 색·모양·ID를 다수결로 덮어 확정하지 않고 충돌을 기록 | **통과:12/12 완료 거부** |
| S3 ROS TF·토픽·완료 파일 | 정상 입력12칸 및 JSON 파일 일치, TF없는 입력0칸 등록. 촬영 시각 TF만 사용 | **통과:12칸·3개 TF 자세·파일/토픽 일치, 독립 관측72건** |


최종 노드 검증: `ros/summary.json`, `ros/puck_survey.json`, `ros/puck_survey.observations.jsonl`. 도메인89·LOCALHOST에서 별도 프로세스2개로 시험. TF 없는 입력등록0, 오래된 입력거부, 불완전완료거부, reset 시 새 survey_id, 완료 후 수집중지 확인. `core_summary.json`은6월드 잡음 입력 및12개 오류 조건. 실제 영상 검출·실물 조사 성공을 뜻하지 않음.

팀 반영 후보는 독립 `perception_survey` 패키지 하나. 기존 robot_interfaces·perception·mission은 수정하지 않으며 자동 bringup 연결은 별도 합의 전까지 추가하지 않음. 시작박스 중심6개는 발제 원점 기준. world_frame이 발제 좌표와 정렬돼 있어야 함. unknown/conflict는 재조사 필요. 슬롯별 초기화는 아직 없으므로 전체 start/reset으로 다시 조사. box yaw는 두 퍽 중심에서 유도하며 직접 박스 모서리 검출 아님.
