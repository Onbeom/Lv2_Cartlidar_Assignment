# [인지→제어] 팔카메라 촬영 시각 TF와 정렬값 무효 처리

## 필요한 연결

인지의 ARM_ALIGN은 앞 D435가 실제 선택한 퍽을 팔 카메라에서 계속 식별해 화면 오차를 전달합니다. 모터 구동이나 집기 성공을 판정하지 않습니다.

- D435 컬러·정렬 깊이·CameraInfo의 촬영 시각과 좌표계를 일치시켜 주세요.
- 팔 카메라 광학 좌표계까지의 TF는 촬영 시각의 실제 관절 자세를 반영해야 합니다. 명령 자세로 대신하면 안 됩니다.
- 카메라 장착 위치·방향은 보정된 외부 파라미터를 사용해야 합니다. 2026-10-27 모델의 모의 영상에서 방향 오차 약1°는 근접 목표의 화면 위치를 수십 화소 바꿨습니다. 새 모델/실물에는 이 수치를 보정값으로 복사하지 않습니다.

## 출력 사용

`/perception/result`의 `offset_valid=true`일 때만 `arm_offset`을 사용해 주세요.

- x: `(검출 중심 u - 화면 폭/2) / (화면 폭/2)`
- y: `(검출 중심 v - 화면 높이/2) / (화면 높이/2)`
- z: 검출 상자 폭 / 화면 폭. 실제 깊이(m)가 아닙니다.
- `offset_valid=false`: 가림·목표 미검출·연결 불확실 등의 상태입니다. 이전 정렬값을 최신 관측으로 사용하면 안 됩니다.

집게에 완전히 가려진 목표의 위치는 영상에서 확인할 수 없습니다. 인지는 이를 무효로 알리고 재관측 시 동일 목표를 다시 연결합니다. 시야 확보 동작과 모터 제어는 제어 파트의 범위입니다.

## 검증 범위

기존모델 261027_1711의 모의 결과입니다. 실제 모터·집기·연속운동 성공을 의미하지 않습니다. 인지 코드의 결과 수치는 개인 작업 폴더 `Cartlidar/sim_render/results/a1_code_261028/`의 원본 JSON으로 별도 관리합니다.
