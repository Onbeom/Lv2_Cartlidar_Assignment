# RL1 학습을 보고 손으로 조절하는 방법

모든 명령은 **PC**(Isaac Lab이 설치된 컴퓨터)에서 실행한다. 학습·평가·화면 재생은 모두 모의 시험이다.

## 1. 화면과 학습의 관계

- 학습(`train.py train`)은 로봇 1024대를 **화면 없이(headless)** 동시에 돌린다. 화면을 그리면 GPU 8 GB가 모자라고 매우 느려지기 때문이다.
- Isaac Lab 화면(Kit 창)은 **이미 저장된 정책(체크포인트)을 재생**해서 보는 것이다(`tools/play_gui.py`). 학습 중에 바뀌는 모습을 실시간으로 보여 주지는 않는다.
- Kit 창에는 보상·목표를 바꾸는 손잡이가 없다. 조절은 아래 2~4장처럼 **설정(명령줄 또는 파일)** 으로 하고 다시 학습한다.
- 학습 중 진행은 TensorBoard 곡선(3장)으로 본다. 학습 도중 저장된 중간 체크포인트(`model_50.pt`, `model_100.pt` …)를 화면으로 재생해 볼 수도 있다. 다만 학습과 동시에 띄우면 GPU·CPU가 함께 느려진다.

## 2. 명령줄로 바꾸기 (선택 · 권장: 파일을 고치지 않고 한 번만 바꿔 볼 때)

`train.py train ...` 뒤에 `env.<경로>=값`, `agent.<경로>=값`을 붙인다. 2026-10-26에 2 iteration 학습으로 반영을 확인한 것은 보상 가중치·목표 바꿈 간격·학습률 세 가지다. 표의 나머지 줄은 같은 방식이지만 아직 확인하지 않았다. 실제로 쓴 값은 기록 폴더의 `params/env.yaml`·`params/agent.yaml`에 남는다.

| 바꿀 것 | 예 | 뜻 |
|---|---|---|
| 보상 가중치 | `env.rewards.tcp_error.weight=-2.0` | 항목: `tcp_error`(오차), `tcp_fine`(가까울수록 +), `self_contact`(자기충돌), `torque_saturation`(토크 포화), `action_rate`(행동 변화), `action_magnitude`(행동 크기), `joint_vel`(관절 속도) |
| 커리큘럼(나중에 바뀌는 가중치) | `env.curriculum.torque_saturation.params.weight=-1.0` | `num_steps`(정책 스텝) 뒤 이 값으로 바뀜 |
| 목표 바꿈 간격 | `env.commands.tcp_target.resampling_time_range=[3.0,3.0]` | 초 단위 |
| 목표 표 | `env.commands.tcp_target.table_path=<npz 경로>` | 다른 목표 표로 학습(4장) |
| 행동 필터(v4) | `env.actions.arm.alpha=0.3` | 클수록 빠르게 반응, 작을수록 부드러움 |
| 학습률 | `agent.algorithm.learning_rate=0.0005` | |
| 정책 탐색 폭 | `agent.actor.distribution_cfg.init_std=0.3` | |
| 학습 길이·환경 수·seed | `--max_iterations 1500 --num_envs 1024 --seed 2` | |

예(PC, 필수 아님 · 보상 가중치를 바꿔 v4를 새로 학습):

```bash
cd ~/git/lv2_next_module/261025_2117/rl1_arm_reach && uv run --project ~/pa-course/IsaacLab-6.1 --frozen --extra isaacsim python train.py train --task Waffle-RL1-ArmReachV4 --num_envs 1024 --seed 1 --max_iterations 1000 --run_name my_try env.rewards.torque_saturation.weight=-0.2
```

## 3. 학습 곡선 보기 (선택 · 권장: 학습 중 진행 확인)

PC에서 TensorBoard를 띄우고 브라우저로 `http://localhost:6006`을 연다. 학습 중에도 30초마다 새로 읽는다. 앱의 브라우저 패널에서는 `.claude/launch.json`의 `rl1-tensorboard`로도 띄울 수 있다.

```bash
~/pa-course/IsaacLab-6.1/.venv/bin/tensorboard --logdir ~/git/lv2_next_module/261025_2117/rl1_arm_reach/logs/rsl_rl/rl1_arm_reach --host 127.0.0.1 --port 6006
```

볼 곡선: `Metrics/tcp_target/position_error`(m, 학습 중 평균 위치 오차), `Episode_Reward/*`(보상 항목별, 에피소드 합 ÷ 초), `Policy/mean_std`(탐색 폭), `Train/mean_reward`(전체 보상). 그림으로 남길 때(선택):

```bash
~/pa-course/IsaacLab-6.1/.venv/bin/python ~/git/lv2_next_module/261025_2117/rl1_arm_reach/tools/plot_learning_curves.py --out ~/git/lv2_next_module/photo/<YYMMDD>_RL1_학습곡선.png
```

## 4. 목표 바꾸기 (선택 · 비권장: 판정 기준과 함께 바꿔야 해서)

- 목표 표는 `tools/make_targets.py`가 만든다. 관절 한계 안 무작위 자세 → TCP 위치 → 바닥·MoveIt 자기충돌 거름. seed·개수를 바꿔 새 표를 만들 수 있다(move_group 실행이 필요하다. 명령은 계획 문서 7장).
- 목표 범위를 좁히는 것(예: 앞쪽만)은 판정 J1~J5의 평가 목표도 바뀌는 일이라, 판정 기준을 먼저 다시 정한다.

## 5. 정책 고르기·화면으로 보기 (선택 · 권장: 학습이 끝난 뒤)

- 기록 폴더 `logs/rsl_rl/rl1_arm_reach/<날짜>_<이름>/`에 50 iteration마다 `model_<n>.pt`가 있다. 마지막은 `model_999.pt`.
- 화면 재생(PC, 화면 있는 터미널, IsaacLab-6.1 폴더에서). 초록 구 = 목표, 빨간 구 = TCP. `--no_mimic`은 Kit 화면 모드에서 집게 mimic 오류로 환경 생성이 실패해서 넣은 화면 전용 옵션이다(학습·평가에는 쓰지 않음). 창을 닫으면 끝난다.

```bash
cd ~/pa-course/IsaacLab-6.1 && uv run --frozen --extra isaacsim python ~/git/lv2_next_module/261025_2117/rl1_arm_reach/tools/play_gui.py --design v4 --checkpoint <model_n.pt 경로> --num_envs 9 --no_mimic --viz kit
```

- 판정(J1~J5) 평가(PC, IsaacLab-6.1 폴더에서):

```bash
cd ~/pa-course/IsaacLab-6.1 && uv run --frozen --extra isaacsim python ~/git/lv2_next_module/261025_2117/rl1_arm_reach/tools/eval_rl1.py --design v4 --checkpoint <model_n.pt 경로> --num_envs 100 --n_targets 1000 --out <결과 폴더>
```

`--design`은 그 체크포인트를 학습한 설계(v2, v3s1, v3s2, v3s3, v4)와 맞춰야 한다. 관찰·행동 구조가 달라서 다른 설계로는 불러오지 못한다.
